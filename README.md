# Interior Locksmith Ltd. — Modern Web Redesign Concept

A clean, high-performance web redesign concept for **Interior Locksmith Ltd.**, the leading 24-hour physical security and locksmith service provider in the British Columbia Interior (Kamloops & 100 Mile House). 

Built with an urgent, trust-focused emergency UI, high-contrast dark-mode theme, interactive service directory, and mobile-first call-to-action routing.

---

## 🔑 Key Features

- **24/7 Emergency Dispatch Header:** High-visibility emergency phone CTA (`250-374-5625`) optimized for instant mobile tap-to-call.
- **Service Categories Grid:** Structured layouts highlighting commercial, residential, automotive transponder key replacement, and safe opening capabilities.
- **Dual-Location Routing:** Showcases physical storefronts in Kamloops and 100 Mile House along with mobile service fleet coverage across the BC interior.
- **Trust & Compliance Badges:** Clean components emphasizing 5-star customer service, licensed technicians, and free security consultations.
- **Mobile-First Responsiveness:** Zero-lag, lightweight single-page layout designed to load instantly for locked-out users on mobile devices.

---

## 🛠️ Tech Stack

- **HTML5 & Modern JS**
- **Tailwind CSS** (via CDN integration)
- **Hosted on:** Vercel
